四、第一次使用前：電腦設定
============================================================

【1. 完整解壓縮 / 完整資料夾】

請保持整個資料夾結構完整，不要只抽出 FakeGpsPatrol.exe 單獨執行，
也不要在壓縮檔內直接開啟。

正常資料夾內至少應包含：

FakeGpsPatrol.exe
adb/
theme.qss
pymobiledevice3/（iOS 功能需要用到）
安卓定位助手APK/（內附 app-debug.apk，Android 功能需要用到，見第五章）

如果要分享給其他人，請把整個資料夾一起複製或壓縮，不要只傳單一 exe，
記得連「安卓定位助手APK」這個子資料夾也要一起帶著。

【2. iOS 使用需要 Apple 裝置驅動】

如果電腦上完全沒有安裝過 iTunes 或 Apple Devices，建議先安裝其中一種，
安裝後重新開機一次，確保 Windows 認得 Apple 裝置。

【3. 防毒 / SmartScreen 提示】

本程式為未簽章程式，第一次執行時 Windows 可能會跳出「Windows 已保護您
的電腦」的提示，這不代表程式有問題，點選「其他資訊」→「仍要執行」即可。
請只從你信任的來源取得本程式。

============================================================
五、Android 使用前設定
============================================================

【1. 安裝定位助手 APK】

資料夾裡的「安卓定位助手APK」子資料夾內附了 app-debug.apk，這是本程式
專用的定位助手 App，Android 手機一定要先裝這個才能用：

1. 把 app-debug.apk 傳到手機上（用 USB 傳檔、雲端硬碟、通訊軟體傳檔皆可）。
2. 在手機上點開 app-debug.apk 進行安裝。
3. 若手機顯示「不允許安裝不明來源 App」或類似提示，請依畫面指示允許這次
   安裝（不同品牌手機文字可能不同，例如「允許來自此來源的應用程式」）。
4. 安裝完成後，請先在手機上打開這個 App 一次。

注意：請只使用本資料夾附上的這個 APK，不要混用來路不明或其他版本，
避免套件不相符、指令送不過去。

【2. 開啟開發者選項】

手機「設定 > 關於手機」，連續點擊「版本號碼」（或「組建編號」）7 次，
依畫面提示輸入密碼後即可開啟開發者選項。

【3. 開啟 USB 偵錯】

「設定 > 開發者選項」，開啟「USB 偵錯」（部分手機顯示為「USB 調試」）。

【4. 選擇模擬定位 App（一定要做這一步，否則定位不會真的改變）】

「設定 > 開發者選項 > 選取模擬位置資訊 App」（不同品牌手機文字可能不同，
例如「選取模擬位置應用程式」「模擬定位應用程式」），選擇剛剛安裝的
專屬定位助手 App。

【5. 插上 USB 並允許電腦】

1. USB 線接上手機和電腦。
2. 手機若跳出「允許 USB 偵錯」或類似提示，請點選允許，
   建議勾選「一律允許這台電腦」。
3. 如果沒有按允許，程式會找得到手機，但無法連線。

【6. 使用時的注意事項】

1. 連線成功後，手機可以切到遊戲/其他 App 使用，不需要停留在定位助手畫面。
2. 請不要把定位助手 App 從最近任務清單裡滑掉，也不要強制關閉它。
3. 如果手機會自動把定位助手背景關掉，導致定位指令送到手機卻沒反應，
   請到手機的電池/耗電管理設定裡，允許定位助手背景執行、關閉它的電池
   最佳化、允許自動啟動（小米/Redmi/OPPO/vivo/realme/Samsung 等品牌
   通常需要額外手動調整這幾項）。

============================================================
六、iOS 使用前設定
============================================================

【1. 信任這台電腦】

USB 接上電腦、解鎖手機，若手機跳出「信任這台電腦」，請點選信任並輸入
裝置密碼。

【2. 開啟開發者模式（兩種方式，視手機是否有設定螢幕鎖定密碼而定）】

方式 A：按「👁️ 顯示開發者模式選項」（推薦，手機有密碼也能用）
  1. USB 接上手機，按下這顆按鈕。
  2. 到手機「設定 > 隱私權與安全性」，應該會看到「開發者模式」這一項。
  3. 手動點開它，照畫面提示重新啟動裝置。
  4. 重新開機後，畫面會再次要求確認開啟，請輸入密碼確認。
  5. 重新插上 USB，回到程式重新連線。

方式 B：按「⚡ 直接自動啟用」（僅限手機沒有設定螢幕鎖定密碼）
  1. USB 接上手機，按下這顆按鈕。
  2. 程式會自動觸發手機重新開機（約需 1-2 分鐘）。
  3. 重開機後，手機畫面會跳出開發者模式確認提示，請在手機上親自點一下
     確認（這一步是 Apple 要求必須由使用者本人操作，無法自動化）。

注意：如果手機目前有設定螢幕鎖定密碼，方式 B 一定會直接失敗
（Apple 系統本身的安全限制），請改用方式 A。

【3. iOS 常見連線問題】

- 「裝置未連接」：確認 USB 線正常、手機已解鎖、已按過「信任這台電腦」。
- 免通道 / RSD 連線後定位沒有變化：通常是開發者模式還沒真的開啟成功，
  請回到手機「設定 > 隱私權與安全性 > 開發者模式」確認狀態是「開啟」。
- iOS 17 以上如果要用「RSD 完整通道」模式，需要另外以系統管理員身分執行
  本程式，才能啟動 tunneld 建立通道。

七、基本使用方式
============================================================

【手動搖桿神盾】

1. 選擇連線方式（Android USB / Android WiFi / iOS 免通道 / iOS RSD完整通道）
2. 按「連線」，等待狀態顯示「已連線」
3. 在地圖上點選位置，或手動輸入座標，按「傳送目前定位」
4. 也可以啟用鍵盤搖桿（WASD），用鍵盤移動座標
5. 「還原真實定位」可以清除模擬定位，讓手機恢復顯示真實位置

【巡邏設定】

1. 在地圖上右鍵新增多邊形頂點，圈出想巡邏的區域，按「完成此區域」
2. 設定「軌道間隔」，按「產生弓字路徑」規劃巡邏路線
3. 設定時速，按「開始」啟動巡邏，可隨時暫停/恢復/終止
4. 已畫好的區域可以存成清單，之後直接載入重複使用

【GPX 路徑工具】

1. 可貼上文字座標、匯入 GPX 檔案，或用地圖右鍵新增座標點
2. 支援最短路徑排序、反轉順序、座標偏移、繞圈路徑產生器
3. 規劃好的路線可以匯出成 GPX / TXT 檔案，或直接套用成巡邏路線

【雙裝置設定】

如果同時有兩支手機要用（一次只插一支也沒關係），可以在這裡分別指定
手機 A / B 各自對應的 Android 裝置序號。

八、常見問題
============================================================

【程式打不開】

1. 確認資料夾是完整解壓縮，不是只抽出單一 exe
2. 確認資料夾裡有 adb、theme.qss、pymobiledevice3 這幾個項目
3. 確認是 Windows 10 / 11 64 位元
4. 確認沒有被防毒軟體誤刪檔案

【Android 連不上】

1. 確認手機已安裝「安卓定位助手APK」資料夾裡的 app-debug.apk
2. 確認開發者選項裡「選取模擬位置資訊 App」已經指定為這個定位助手 App
3. 確認手機已開啟 USB 偵錯，並允許這台電腦
4. 換一條 USB 線或不同的 USB 孔測試

【Android 顯示已連線，但手機定位沒有反應】

1. 確認「選取模擬位置資訊 App」選的就是本程式附的定位助手 App
   （不是其他假GPS App，也不是空白未選取）
2. 確認手機的「定位服務」（GPS）本身有開啟
3. 確認定位助手 App 沒有被最近任務清單滑掉、沒有被強制關閉
4. 確認定位助手沒有被系統背景耗電管理自動關掉（見第五章第 6 點）
5. 可以先用地圖 App（Google Maps）測試定位是否真的改變，排除是遊戲
   本身沒有讀取到最新定位，而不是本程式的問題

【iOS 連不上 / 定位沒有反應】

1. 確認 USB 已插好、手機已解鎖、已信任這台電腦
2. 確認開發者模式已經真正開啟（設定 > 隱私權與安全性 > 開發者模式）
3. 如果看起來「已連線」但手機定位沒有變化，通常就是開發者模式尚未
   完成，請重新走一次第六章的設定流程

【巡邏時 iOS 定位跳來跳去不平順】

程式已針對 iOS 的巡邏改用連續播放模式讓移動平順，如果還是不平順，
確認連線方式是否為「iOS 免通道」或「iOS RSD完整通道」，並確認開發者
模式已經開啟成功。
