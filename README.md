# Fake GPS Patrol（雙系統定位神盾 - 精簡版）v2.0

Windows 桌面工具，透過 USB / WiFi 對 Android、iOS 手機發送虛擬定位（假 GPS）。

## 主要功能

- **手動控制**：地圖點選、鍵盤 WASD 搖桿、滑鼠拖曳搖桿、輸入座標或地名直飛
- **弓字型巡邏**：在地圖上圈出區域，自動規劃來回掃描路線
- **路線產生器**（v2.0 全新改寫，共五個分頁）
  - 一般路線：文字貼上 / 地圖點選 / 匯入 GPX、CSV、JSON，節點可拖曳排序、
    最短路徑最佳化、設定續跑起點，執行模式支援跑一次 / 往返折返 / 持續循環
  - 種花路徑：多個中心點各自繞圈，可設定半徑、圈數、抵達與出發前的停留秒數，
    支援第二圈與花點間瞬移／直線走過去
  - 跳躍路徑：瞬移到定點、停留、往下一點走幾公尺再跳
  - 同心圓：由中心點往外一圈一圈產生路線
  - 已存路線：把調好的路線連同設定存起來，之後可直接執行或載回面板修改
- **收藏夾 / 分類 / 執行歷史**：常用座標可分類管理、匯出匯入，最近執行過的
  路線與座標會留下紀錄可回頭再用
- **雙裝置**：可同時對兩支手機（A / B）各自送定位、各自巡邏
- **團體種花**：多人同一條路線、同一個座標一起走，房主帶頭、每個花點結束
  會等所有人跟上再繼續（需要自行部署房間伺服器，見 `cloudflare_worker/`）
- **工具與設定**：字體大小調整、一鍵匯出診斷日誌、檢查更新

所有座標運算都處理了 ±180 度換日線，在換日線附近使用不會算出繞地球一圈的路徑。

## 下載使用（不用裝 Python，直接執行）

到本倉庫的 **[Releases](../../releases)** 頁面下載最新版的 zip 檔，解壓縮後
雙擊 `FakeGpsPatrol.exe` 即可執行。

使用前請務必先閱讀壓縮包內的
[`使用前說明與免責聲明.txt`](./使用前說明與免責聲明.txt)，
裡面有 Android / iOS 各自的連線設定步驟與常見問題排解。

## 從原始碼執行 / 自行打包

```bash
pip install -r requirements.txt
python main.py
```

若要打包成給別人使用的獨立執行檔（不需要對方安裝 Python），執行：

```bash
build_release.bat
```

打包腳本會另外把 `pymobiledevice3` 也凍結成一支獨立執行檔一起附上，讓
iOS 功能在沒有安裝 Python 的電腦上也能使用；第一次執行會比較久（約
5-15 分鐘），之後若沒有升級 `pymobiledevice3` 版本，可以設定環境變數
`SKIP_PMD3=1` 跳過這一步。

Android 功能另外需要手動安裝定位助手 APK 並設為模擬定位 App，詳見
使用說明文件第五章。
